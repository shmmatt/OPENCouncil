## Permits & Licenses

### Building Permit

Required for new construction, additions, decks, sheds >120 sq ft, demolition

**Fee:** See Planning Board Fee Schedule (2023) - varies by project type and value
**Contact:** Code Enforcement Officer, 603-539-4181 ext. 107
**Application:** https://www.ossipee.org/code-enforcement

### Driveway Permit

Required for new driveways or changes to existing driveway location/width onto town roads

**Fee:** Check with Road Agent
**Contact:** Road Agent, 603-539-4181

### Septic System Permit

Required for new or replacement septic systems

**Contact:** NH Department of Environmental Services (NHDES)
