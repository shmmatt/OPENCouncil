### 1. The Shadcn Color Formatting Trap
Shadcn UI is incredibly picky about how CSS variables are defined in `index.css`. If the agent writes `--primary: hsl(205, 61%, 26%);`, it will break every Shadcn component in your app. 
* **Add to Theme Tokens Task:** *"CRITICAL: Format the CSS variables strictly for Shadcn UI. Do not use the `hsl()` wrapper. Use raw space-separated values (e.g., `--primary: 205 61% 26%;`)."*

### 2. The Mobile Layout Collapse
The 8-col / 4-col / 3-col "bento grid" on the News Feed page will look beautiful on desktop but will completely shatter on a phone if the agent hardcodes it. The same goes for the new left sidebar.
* **Add to Shared Civic Layout & News/Feed Tasks:** *"Ensure the layout is fully responsive. The left sidebar must be collapsible on mobile devices (using Shadcn's Sheet or Sidebar mobile patterns). The News/Feed bento grid must cleanly stack into a single vertical column on mobile screens (`flex-col` or `grid-cols-1`)."*

### 3. The Floating Chat Input
In your chat mockup, the input bar isn't a standard full-width footer—it's a floating, centered, rounded pill hovering above the bottom of the screen. Standard LLM code-gen will default to a clunky, full-width block attached to the bottom of the window.
* **Add to Chat Page Restyle Task:** *"Style the chat input area exactly as mocked up: a centered, floating, rounded container with a soft shadow, rather than a full-width sticky footer. Ensure it hovers slightly above the bottom of the screen."*
