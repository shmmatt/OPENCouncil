### The Two Critical Gotchas

**1. The Native Google Doc Trap (Export vs. Media)**
The agent's plan states: *Download URL: `?alt=media&key={apiKey}` — direct binary download for public files*.
This works perfectly if the town uploaded an actual `.pdf` file to Drive. However, if the town clerk created a native **Google Doc** for the minutes, `alt=media` will throw a 403 error. Native Google Docs cannot be downloaded directly; they must be *exported*.

* **The Fix:** The agent must check the `mimeType`. If it is `application/vnd.google-apps.document`, it must use the `/export?mimeType=application/pdf` endpoint instead of `?alt=media`.

**2. The Recursive Folder Query**
The Google Drive API doesn't let you just say "give me everything in this folder and its subfolders." It operates on a flat structure. To get files in a specific folder, you have to query `'{folderId}' in parents`.

* **The Fix:** To do this recursively, the agent's `listFolderRecursive` function needs to specifically query for both PDFs *and* Folders (`mimeType='application/vnd.google-apps.folder'`). When it finds a subfolder, it needs to grab that new ID and run the query again, building the path (e.g., "Board of Selectmen/2025") as it goes down the tree.
