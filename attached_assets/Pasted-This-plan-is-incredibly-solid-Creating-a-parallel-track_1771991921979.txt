### The Gap: URL Filtering vs. DOM/Text Filtering

In Task T002, the plan states:

> *"Applies source.excludePatterns — skip any URL matching exclude patterns during BFS and document download"*

This works perfectly for the NHMA paywall because the URL contains `/store/` or `/cart/`.

But remember the **NH Supreme Court Slip Opinions**? The URL for a court case PDF usually looks generic, like `https://www.courts.nh.gov/sites/g/files/ehbemt471/files/documents/2026-02/24-0125.pdf`. The municipal keywords ("Town of", "ZBA") are **not in the URL**; they are in the HTML text of the link itself or the adjacent table cell (e.g., `<td>Smith v. Town of Ossipee</td> <a href="24-0125.pdf">Opinion</a>`).

If the crawler's BFS discovery phase only evaluates the raw URL string against `linkPatterns` and `excludePatterns`, it will blindly download every single criminal and divorce case on the docket because they all share the same generic URL structure.
