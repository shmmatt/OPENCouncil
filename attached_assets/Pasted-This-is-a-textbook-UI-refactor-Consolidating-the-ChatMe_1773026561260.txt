### 2. The Feedback Button API Trap

The plan suggests moving the `FeedbackButtons` into the shared `ChatMessageBubble`.

In the main chat page, hitting "Thumbs Up" or "Thumbs Down" likely triggers a database mutation to save that feedback to a specific `messageId` or `sessionId`. **The Fix:** Instruct the agent to keep the component "dumb." The `ChatMessageBubble` should accept an `onFeedbackSubmit?: (feedbackType: 'up' | 'down') => void` prop. This allows the parent pages (`chat.tsx` and `feed-layout.tsx`) to handle the actual database mutation logic themselves.
